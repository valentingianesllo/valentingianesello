OVERVIEW

Context

Differential geometry is a mathematical field that studies geometric objects using tools from differential calculus. It provides a framework for describing curved spaces, surfaces and manifolds.

Its concepts play an important role in modern mathematics and theoretical physics, particularly in general relativity, where spacetime is described using the language of geometry.

SUBJECT

Content of the project

This project provides an introduction to the fundamental concepts of differential geometry, from the mathematical description of curves and surfaces to the more general framework of differentiable manifolds.

The aim is to understand the geometric structures that allow us to describe curved spaces and to explore the mathematical tools used to study them.
